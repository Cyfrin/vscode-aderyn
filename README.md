# Aderyn for VS Code — retired

> [!IMPORTANT]
> The Aderyn extension is retired and no longer maintained. Do not install it in
> new environments. Aderyn CLI release downloads have been withdrawn and its npm
> package is retired, so existing copies may fail when they try to install or
> update the CLI. There are no supported extension installation or update paths.

## Remove existing installations

Delisting the extension and withdrawing its downloads do not uninstall copies
already installed in your editor.

1. Open the **Extensions** view in VS Code.
2. Find the installed **Aderyn** extension from **Cyfrin** (`cyfrin.aderyn`) and
   select **Uninstall**.
3. Reload or restart the editor if prompted.

Repeat this for other editor profiles, remote environments such as WSL or SSH,
and compatible editors where you installed Aderyn.

If you installed the Aderyn CLI separately, also follow its
[retirement and removal guidance](https://github.com/Cyfrin/aderyn#installation-and-removal).
